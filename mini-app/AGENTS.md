# Mini App

- Компоненты находятся в `components/`, хуки — в `hooks/`, общие runtime-утилиты — в `utils/`.
- Не создавай локальный аналог компонента, который уже есть в UI kit.
- Используй токены и все шрифты из соседней папки `../primitives`.
- Для UI-иконок используй только `../primitives/material-symbols-react`; не добавляй локальные SVG-иконки.
- Не добавляй компонентные прокси-токены. Используй базовые `--ui-space-*`, `--ui-radius-*` и общие `--ui-layout-*` напрямую.
- Стили компонентов держи рядом с компонентами. Глобальные стили документа разрешены только в опциональном `styles/app-shell.css`.
- Примеры компонентов и экранов находятся только в `storybook/examples/`; runtime-код не должен импортировать Storybook.
- Для Telegram используй `lib/twa`. Telegram-функции должны безопасно работать в обычном браузере.
- Перед завершением запускай `yarn verify` из `mini-app/storybook`.
