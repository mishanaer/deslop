# Mini App

Библиотека React-компонентов для Telegram Mini Apps на основе токенов, шрифтов
и Material Symbols из `@deslop/primitives`.

## Storybook

```bash
(cd mini-app && corepack yarn install --immutable)
(cd mini-app && corepack yarn dev)
```
