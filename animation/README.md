# animation

Два переносимых скилла для посимвольного появления текста. В каждом есть
инструкция для агента, описание параметров и готовый пример для браузера.

## Выбрать эффект

- [soft-appearance](./soft-appearance/SKILL.md) — спокойное появление снизу без
  размытия. Подходит для предложений, многострочных заголовков, длинного текста
  и страниц с несколькими анимациями
- [spring-appearance](./spring-appearance/SKILL.md) — акцентное появление с
  подъёмом, размытием, поворотом и мягкой пружиной. Подходит для короткой фразы:
  лучше 2–4 слова, максимум одно короткое предложение

Если сомневаетесь, выбирайте `soft-appearance`: он легче для браузера и не
перетягивает внимание с текста.

## Установить скилл

Скопируйте одну или обе папки в `.agents/skills/` своего проекта:

```text
.agents/skills/
├── soft-appearance/
└── spring-appearance/
```

После этого укажите скилл в запросе к агенту:

```text
Примени $soft-appearance к этому тексту.
```

```text
Примени $spring-appearance к этому короткому заголовку.
```

Если установлены оба скилла, агент выберет эффект по длине текста и правилам
из `SKILL.md`.

## Использовать без агента

- Для `soft-appearance` скопируйте файлы
  `assets/waapi/soft-appearance.js` и `assets/waapi/soft-appearance.css`
- Для `spring-appearance` скопируйте файлы
  `assets/waapi/spring-appearance.js` и `assets/waapi/spring-appearance.css`

Оба эффекта работают без зависимостей через встроенный браузерный API
анимаций.

## Посмотреть

[Сторибук](./storybook/) показывает каждый эффект на коротком и трёхстрочном
тексте. Запустите сервер из корня репозитория:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173/animation/storybook/`.
