# animation

Скиллы с готовыми интерфейсными анимациями.

## text-appearance

[Text Appearance](./text-appearance/SKILL.md) по очереди проявляет символы
текста снизу вверх. Внутри — только эффект
`per-character-rise`.

### Подключение

Скопируйте папку `text-appearance` в `.agents/skills/` своего проекта. Затем попросите агента применить `$text-appearance` к нужному тексту.
